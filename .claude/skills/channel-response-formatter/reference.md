# Channel Response Formatter Reference

## Overview
Formats agent responses appropriately for each channel (email, WhatsApp, web) with proper length limits, tone, and structure.

## Key Capabilities
- Channel-specific formatting
- Length enforcement
- Tone adaptation
- Template application
- Multi-message splitting (WhatsApp)

## Constitutional Alignment
- **Principle 4: Channel-Appropriate Responses** - Core requirement
- **Principle 1: Multi-Channel First** - Channel awareness
